# 미노출 진단 — 우리 이름이 답에 안 나올 때 어디부터

고객이 묻는 질문에 AI 답변이 우리를 부르지 않을 때 **원인을 앞에서부터 하나씩 지운다.**
앞 단계가 막혀 있으면 뒤 단계에 자료를 더해도 효과를 확인할 수 없다. 각 단계는
**확인 → 막혔으면 고칠 것 → 자료를 더할 곳** 순서로 읽는다. 상세 방법은 링크한 문서가 정본이다.

## 0. 정말 안 나오나 — 측정부터 확인

- [ ] `measure report`의 칸이 `0/10`인가 `미측정`인가. 못 잰 것은 0이 아니다 ([coverage](coverage.md))
- [ ] 질문이 실제 고객 문장인가. 단어 두세 개 검색어와 상황·조건이 담긴 문장은 답이 다르다 ([intent](intent.md))
- [ ] 브랜드 질의와 비브랜드 질의를 나눠 봤나. 브랜드 질의에서도 안 나오면 색인·크롤러·엔티티 사고다 ([measure](measure.md) 2번)
- [ ] **언급과 인용을 구분한다.** 이름은 나오는데 우리 링크가 없으면 4단계(제3자 채널) 문제일 가능성이 높고,
      이름도 안 나오면 1~3단계부터 본다

## 1. 들어올 수 있나 — 접근

| 확인 | 신호 | 고칠 것 |
|---|---|---|
| robots 정책 | `AI_CRAWLER_BLOCKED` · `AI_CRAWLER_PARTIAL` | 목표 엔진의 검색·열람 봇 허용 ([crawlers](crawlers.md)) |
| 원시 HTML 링크 | `LINKS_NOT_IN_HTML` · `SITEMAP_ONLY_PAGES` | 메뉴·목록·예약 링크를 `<a href>`로. 스크립트를 실행하지 않는 크롤러·에이전트는 사이트맵을 보지 않고 링크를 따라간다 |
| 원시 HTML 본문 | `THIN_TEXT` | SSR 또는 사전 렌더링 ([seo](../lanes/seo.md) 1번) |
| 방화벽·봇 차단 | 서버 접근 로그 · 호스팅 대시보드의 봇 분류 | 검색·열람 봇이 403·챌린지를 받는지 확인한다. 실제 봇은 IP로도 검증되므로 봇 이름만 흉내 낸 요청으로 판정하지 않는다 |
| 검색 색인 | GSC · Bing · 서치어드바이저 | 색인이 없으면 Gemini·Copilot·네이버 계열은 닿을 경로가 좁다 ([geo](../lanes/geo.md) 엔진 매트릭스) |

## 2. 와서 답을 찾을 수 있나 — 자사 사실

AI가 우리를 비교표에 넣으려면 **가격·조건·기간·연락처가 본문에 글자로** 있어야 한다.
"가격 문의", "상담 후 안내"만 있는 페이지는 비교할 값이 없어 다른 회사가 대신 들어간다.

- [ ] 아래 다섯 종류의 페이지가 있는지 점검한다. 없는 것이 다음에 만들 페이지다

| 페이지 | 담을 것 |
|---|---|
| 브랜드 정의 | 누구를 위한 회사인지 한 문단. 업종·카테고리 이름을 모든 표면에서 같게 ([llmo](../lanes/llmo.md) 1번) |
| 제품·서비스 | 핵심 속성·가격·조건·비교 기준을 표로. 단위와 기준일 포함 |
| 상황별 가이드 | 고객 상황 하나당 한 편 — 그 상황의 조건으로 선택지를 비교 |
| 근거·FAQ | 시험·인증·사례·후기 요약과 실제로 받은 질문 ([aeo](../lanes/aeo.md)) |
| 최신 정보 | 가격·재고·운영시간·정책의 현재 값과 수정일 |

- [ ] 문장은 떼어 가도 성립하게 쓴다 — 조건·예외·기준일을 같은 문장에 ([aeo](../lanes/aeo.md) 점검 4항)
- [ ] 구조화 데이터는 보이는 값과 같을 때만. 가격은 화면에 표시된 값만 `site.json`에 넣는다

## 3. 질문의 조건에 답하나 — 질문 분해

상황이 담긴 질문은 여러 조건을 한꺼번에 말한다. 답변은 그 조건마다 근거가 있는 후보를 고르고,
**한 조건이라도 근거가 비면 그 자리에 다른 후보가 들어간다.**

- [ ] 측정 질문을 다섯 칸으로 나눈다: **상황**(누가·언제) / **기준·제약**(예산·크기·규모) /
      **피하고 싶은 것** / **취향**(분위기·스타일) / **검증 근거**(후기·평가)
- [ ] 칸마다 우리 페이지에 답하는 문장이 있는지 표시한다. 빈칸이 보강할 내용이다
- [ ] 답변이 경쟁 후보를 고른 **이유**를 그대로 적는다. 같은 축의 사실이 우리에게 있는데 안 적혀 있으면 2단계,
      실제로 없으면 제품·서비스의 문제다 — 문장으로 메우지 않는다
- [ ] 사실은 **속성 → 이유 → 근거 → 평가**로 이어져야 추천 문장이 된다 ([reputation](../lanes/reputation.md) 1번)

"○○ 추천" 같은 질문은 측정 대상이다. 다만 직답 페이지를 따로 만들지 않고, 상황별 가이드의
조건 비교표로 답한다 ([intent](intent.md) 2번의 예측·권유형 제외는 직답 페이지 기준이다).

## 4. 남도 같은 말을 하나 — 제3자 채널

답변은 회사가 직접 한 말보다 **남이 확인한 말**을 먼저 쓰는 경향이 있다. 어디에 자료를 더할지는
일반론이 아니라 **우리 질의 세트에서 실제로 근거가 된 채널**로 정한다.

```bash
python <skill-root>/tools/seo_geo.py measure report <audit.json>
# MEASURE.md → "출처 채널 — 답변이 무엇을 근거로 썼나"
```

이 표가 채워지려면 측정할 때 **우리 것이 아닌 출처 URL도 전부** 적어야 한다
(브라우저 측정은 `--sources`, 수동 폼은 출처 URL 칸). 출처를 적지 않은 회차는 분모에서 빠지고 `미기록`으로 표시된다.

| 자주 나오는 채널 | 자료를 더하는 방법 | 참고 |
|---|---|---|
| 영상 | 설명·비교 영상. 수치와 원문 링크는 제목·설명란·자막에 글자로 | [geo](../lanes/geo.md) 채널 지도 |
| 오픈 블로그 | 자사 원본과 **같은 수치·같은 기준일**의 오픈웹 판 | [geo](../lanes/geo.md) 채널 지도 |
| 네이버 블로그 | 원본 요약 + 자사 원문 링크 (투트랙) | [naver](../lanes/naver.md) 3번 |
| 위키 | 직접 편집 대상이 아니다. 사실 오류만 근거를 붙여 정정 요청 | [reputation](../lanes/reputation.md) 3번 |
| 커뮤니티·Q&A | 직접 게시하지 않는다. 실제 고객 경험이 같은 말로 나오게 한다. 자사 FAQ를 문답형으로 | [intent](intent.md) 포맷 |
| 오픈마켓·쇼핑 | 상품 등록 정보의 스펙·가격·옵션을 자사 원본과 일치시킨다 | — |
| 지도·리뷰·예약 | 프로필의 주소·영업시간·가격 최신화, 리뷰 응대 | [naver](../lanes/naver.md) 4번 · [daum](../lanes/daum.md) · [reputation](../lanes/reputation.md) 4번 |
| 채용·기업정보 | 공식 소개문 그대로, 담당 부서 지정 | [reputation](../lanes/reputation.md) 4~5번 |
| 언론 | 수치·기준일이 있는 발표, 공식 문구 통일 | [geo](../lanes/geo.md) 채널 지도 |
| 미분류(경쟁사 공식 사이트 등) | 그 페이지가 글자로 적은 사실을 우리 페이지와 비교 → 2·3단계 | — |

## 5. 다음 달 같은 질문으로 — 반복

- [ ] 처음에는 고객 상황 5개 안팎, 상황마다 질문 몇 개로 시작해 [measure](measure.md) 2번의 40~50개 범위로 늘린다
- [ ] 회차마다 **안 불리는 상황**과 **틀리게 설명된 사실**을 목록으로 남긴다. 틀린 설명은 [measure](measure.md) 7번 정정 절차로
- [ ] 2~4단계에서 보강한 날짜를 기록하고, **같은 질문 세트**로 다시 잰다 (`drift compare`). 질문을 바꾸면 비교가 끊긴다
- [ ] 보강과 인용 변화 사이의 인과는 단정하지 않는다 ([evidence](evidence.md))

## 하지 말 것

후기 조작·대가성 리뷰, 신원을 숨긴 커뮤니티 게시, 숨김 텍스트, 내용 변경 없는 날짜 갱신,
같은 글의 대량 복제. 들키는 순간 그 채널 전체에서 신뢰를 잃는다 ([reputation](../lanes/reputation.md) 6번).
