# 엔진별 측정 레시피 — 실제로 어떻게 뚫는가

`measure.md`가 **무엇을 재고 어떻게 적을지**를 정한다면, 이 문서는 **각 엔진에 실제로
어떻게 접근하는가**를 다룬다. 전부 실측으로 확인한 것이고, 함정은 직접 밟아본 것만 적었다.

> 기준일 2026-09-11. 엔진 UI는 자주 바뀐다 — 안 되면 이 문서를 고쳐라.

---

## 자동화 가능 범위

| 표면 | 자동화 | 방법 |
|---|---|---|
| 네이버 자연검색 | **완전** | `requests` + PC/모바일 UA |
| 네이버 AI 브리핑 | **완전** | fender 블록 판정 → SSE API |
| 다음 웹검색·AI요약 | **완전** | 헤드리스 Chrome DOM 덤프 |
| 구글 자연검색·AI개요 | **완전** | 헤드리스 + 브라우저 UA |
| Perplexity | 반자동 | **로그인 필요**(2026-09 변경). 스레드 URL은 공개라 캡처 가능 |
| ChatGPT · Gemini · Claude | 반자동 | 로그인 필요, 중립 모드로 브라우저 구동 |
| GSC · 서치어드바이저 색인 수 | **수동** | 계정 로그인 — 여기만 사람이 한다 |

"사람이 확인"으로 남길 것은 마지막 줄뿐이다.

## 네이버

PC `search.naver.com/search.naver?query=`, 모바일 `m.search.naver.com/...`.
둘 다 `requests`로 받힌다. **모바일을 기본으로 본다** — 네이버는 모바일 우선이다.

### AI 브리핑

1. **발동 판정은 SERP HTML로 한다.** `data-block-id="ai-briefing/..."` fender 블록이 있으면 발동.
2. 블록 안 `entry.bootstrap(...)` 페이로드에 두 변종이 있다.
   - `aibAnswer` — `props.summary` · `props.sources`가 **HTML에 인라인**. 추가 요청 불필요
   - `aibAnswerRuntime` — `props.apiURL`(`aib-api.naver.com/aibrender.naver`)로 **SSE 스트림**
3. SSE는 `event:<이름>` 다음 줄 `data:<JSON>` 구조. `sources`(화면 출처 칩)와
   `footnote_sources`(근거 풀)의 `data`는 **객체가 아니라 배열 그 자체**다.

```
⚠️ Accept-Encoding 에 br 를 넣지 마라 — 본문이 통째로 깨진다. gzip, deflate 만.
⚠️ API는 아무 질의에나 답을 만들어 준다. API 응답만으로 "떴다"고 판정하면 틀린다.
   발동 여부는 반드시 SERP HTML의 fender 블록으로 본다.
```

## Perplexity

**2026-09-11 기준 비로그인 측정은 막혔다.** 질의는 접수되고 스레드 URL(`/search/<uuid>`)까지
만들어지지만, 답변 자리에 *"가입한 뒤 요청을 다시 보내주세요"* 가 뜬다. 스레드는 생겼는데
내용이 없으므로 **이걸 "인용 0"으로 세면 안 된다** — `unmeasured` 다.

- 로그인 브라우저에서 재라. 사람은 로그인만 하고 질의·판정은 에이전트가 한다.
- 스레드 URL 자체는 여전히 공개 접근되므로 **증빙 캡처는 그 URL로** 뜰 수 있다.
- 첫 방문에 가입 모달이 덮는다. 닫고 나서 입력해야 질의가 들어간다.

```
⚠️ 헤드리스로 /search?q= 를 직접 열어도 로그인 벽이다.
⚠️ 이 절은 자주 바뀐다. 안 되면 고쳐라 — 낡은 "비로그인 가능" 기술을 믿고
   0으로 적는 것이 가장 나쁘다.
```

## ChatGPT

| 상태 | URL | 동작 |
|---|---|---|
| 로그아웃 | `chatgpt.com/?q=<질의>` | **자동 전송** |
| 로그인 | `chatgpt.com/?temporary-chat=true&prompt=<질의>` | 입력만 되고 **전송은 수동** |

로그인 상태로 잰다면 **임시 채팅이 필수**다. 안 켜면 계정 히스토리·메모리가 답에 섞인다.

```
⚠️ 창 크기가 바뀌면 전송 버튼 좌표도 바뀐다. 좌표보다 요소 참조로 클릭하라.
⚠️ Enter 로 전송되지 않는 경우가 있다. 전송 버튼을 요소 참조로 눌러라.
```

로그인 상태에서 질의를 정확히 넣는 가장 확실한 방법은 URL 파라미터다 —
`chatgpt.com/?temporary-chat=true&prompt=<URL 인코딩된 질의>` 로 열면 글자가 그대로 들어간다.
전송만 버튼으로 누르면 된다.

## 한글 띄어쓰기가 사라지는 문제 — 모든 엔진 공통

브라우저 자동화의 타이핑은 **한글 단어 사이 공백을 자주 흘린다.**
`장기렌트 업체 추천해줘` 가 `장기렌트업체추천해줘` 로 들어가면 **질의 세트가 깨진 것**이고,
그 결과를 같은 질의의 관측으로 적으면 추이가 오염된다. **보내기 전에 반드시 입력값을 읽어 확인하라.**

효과가 있었던 순서대로:

1. **URL 파라미터** — 지원하는 엔진(ChatGPT)에서 가장 확실하다
2. **`insertText` 커맨드** — contenteditable 편집기(Claude·Gemini)에 실제 입력 이벤트를 발생시킨다

   ```js
   const e = document.querySelector('[contenteditable="true"]');
   e.focus();
   document.execCommand('selectAll', false, null);
   document.execCommand('insertText', false, '장기렌트 업체 추천해줘');
   ```

3. 단어마다 나눠 치고 사이에 space 키를 따로 누르기 — **되다 안 되다 한다.** 확인 필수

```
⚠️ 2번으로 글자를 넣어도 편집기 내부 상태가 갱신되지 않아 Enter 가 안 먹을 수 있다.
   전송 버튼을 요소 참조로 눌러라.
⚠️ 값을 확인하지 않고 보낸 결과는 기록하지 마라. 다른 질의를 잰 것이다.
```

## Gemini · Claude

둘 다 **비로그인 접근이 막혀 있다.** 로그인 브라우저에서 중립 모드로 재야 한다.

### 되는 순서 — 이 순서를 지키면 둘 다 자동으로 잰다

화면 문구로 상태를 판정하려다 두 번 틀렸다. **버튼의 aria-label 이 정확한 상태다.**

| 엔진 | 꺼짐 | 켜짐 |
|---|---|---|
| Gemini | `임시 채팅 사용 설정` | `임시 채팅 사용 중지` |
| Claude | `시크릿 사용` | `시크릿 모드 종료` |

1. **빈 입력창에서 모드를 먼저 켠다.** Gemini는 **작성 중이면 토글이 먹지 않는다.**
   버튼을 누른 뒤 위 라벨이 뒤집혔는지 확인한다.
2. **`insertText` 로 질의를 넣는다** (「한글 띄어쓰기」 절 참조). 넣은 값을 다시 읽어 확인한다.
3. **전송 버튼을 눌러 보낸다.** `insertText` 뒤의 Enter 는 먹지 않는다 —
   편집기 내부 상태가 따라오지 않아서다. `메시지 보내기` 버튼을 누른다.
4. 20~30초 기다린 뒤 **`main` 전체 텍스트**로 답변을 읽는다.

```
⚠️ Gemini 의 <model-response> innerText 는 "Gemini의 응답" 만 준다. 답변 본문이 안 잡힌다고
   "응답 없음"으로 판정하지 마라 — main 전체를 읽으면 멀쩡히 있다. 2026-09-11 에 이걸로
   한 번 미측정 처리했다가 되돌렸다.
⚠️ Claude 시크릿 모달은 직전 대화를 복원한다. URL 재방문으로는 초기화되지 않는다 —
   모달을 닫았다가 유령 아이콘으로 다시 열어야 새 대화다.
⚠️ Gemini 는 `?q=` 같은 프롬프트 URL 파라미터가 없다 (2026-09-11 확인). 입력은 2번으로.
```

### Claude 시크릿은 **비브랜드 질의도 오염시킨다**

「장기렌트 업체 추천해줘」라는 브랜드 없는 질의에 Claude 가
*"(측정 대상 회사명)과 비교 검토 중인가요?"* 라고 되물었다. **계정 프로필에서 회사를 알고 있는 것**이지
웹에서 찾은 것이 아니다. 이 상호 언급을 인용·언급으로 세면 **없는 성과가 생긴다.**

- 웹 UI 로 잰 Claude 수치는 **상호 언급을 빼고** 집계한다 (`measure.md` 「엔진별 중립 모드」)
- 오염 없는 Claude GEO 수치가 필요하면 **API 경로**를 쓴다 —
  `measure.py auto` 가 Messages API + `web_search` 서버 도구로 재고, **실제 인용된 URL만** 센다.
  단 API 와 웹 UI 는 **다른 표면**이므로 같은 칸에 넣지 않는다 (로그의 cohort 가 갈라 준다)

```
⚠️ Claude 시크릿은 저장·학습만 막고 계정 프로필은 살아 있다.
   프로필에서 나온 서술은 웹 인용이 아니다 — measure.md 「엔진별 중립 모드」 규칙대로 집계에서 뺀다.
```

### 답변 거부도 데이터다

Gemini는 저신용·무심사 같은 **금융 규제 민감 표현**에 가드가 걸려 답변을 거부하는 경우가 있다.
거부되면 **경쟁사도 함께 못 나온다** — 그 키워드로는 경쟁 자체가 성립하지 않는다.
질의 세트를 고정하기 전에 엔진별 거부 여부를 먼저 확인하고, 거부되는 표현은
**같은 의도의 중립 표현으로 바꿔** 측정한다.

## 증빙 캡처 — 헤드리스 Chrome

```bash
chrome --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
  --disable-blink-features=AutomationControlled \
  --user-agent="<정상 Chrome UA>" --lang=ko-KR \
  --user-data-dir="<임시 프로필>" --window-size=1400,2400 \
  --virtual-time-budget=15000 --screenshot="<출력경로>" "<URL>"
```

```
⚠️ 상대경로는 실패한다. 절대경로를 쓰되 백슬래시 대신 슬래시를 써라.
⚠️ 파일명에 한글을 넣으면 기록에 실패한다. ASCII로 저장한 뒤 옮겨라.
⚠️ --virtual-time-budget 은 타이머만 앞당긴다. 네트워크 응답은 실시간이라
   스트리밍으로 답하는 엔진(ChatGPT·Perplexity)은 생성 도중에 찍힌다.
```

DOM만 필요하면 `--dump-dom`이 캡처보다 가볍고 파싱하기 좋다.

## 질의 세트는 파일로 고정한다

세트가 바뀌면 추이가 끊긴다. `queries.txt`를 저장소에 두고, 바꿔야 하면
**새 파일을 만들고 옛 파일을 남긴다.** 같은 날 두 사람이 다른 세트로 재면 비교가 불가능해진다.

- 브랜드 세트와 비브랜드 세트를 **파일부터 나눈다** (`measure.md` 참조)
- 세트를 바꾼 날짜와 이유를 파일 머리에 주석으로 남긴다
