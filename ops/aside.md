# Aside 선택적 사용

## 도구 선택

- 코드 수정, 공개 문서 조회, HTTP 진단, 사이트맵·robots 검사, 로그 집계에는 기존 도구를 사용한다. 이 작업만으로 Aside를 호출하거나 설치·로그인 상태를 점검하지 않는다.
- 실제 AI 웹 UI의 로그인 세션이 필요한 경우, Aside에 해당 세션이 있으면 우선 사용한다. 세션은 만료될 수 있으므로 사용할 때 현재 화면에서 확인한다.
- 다른 브라우저에만 적합한 세션이 있거나 Aside가 사용할 수 없으면 기존 브라우저 도구를 사용한다. 자동 설치·쿠키 이전·재로그인을 강제하지 않는다.
- 계정 콘솔 조회는 승인된 사이트·계정·읽기 범위에서만 수행한다. 게시·설정 변경은 별도 작업 범위에 따른다.

## 실행과 기록

사용이 필요할 때 `aside --help`와 `aside guide repl`을 읽는다. 화면 관측과 정해진 조작은 REPL을 우선하고, 복합 작업 위임이 유리할 때만 `aside exec`를 사용한다. MCP는 선택 사항이며 CLI만으로도 호출할 수 있다.

[측정 실행 지침](measure-playbook.md)에 따라 고정 질의와 회차, 언어·지역, 실제 웹 제품, 검색·로그인 상태를 유지한다. 중립 모드를 확인하고 질문을 전송하기 전에 입력값을 대조한다. 계정 기억·맞춤 설정의 잔여 영향은 관측 한계로 기록한다.

`collect <audit.json> --browser`로 측정 자리를 준비하고, 응답 완료와 실제 출처 URL을 확인한 관측만 `collect --record`로 되받는다. 로그인·CAPTCHA·응답 확인 실패는 미인용이 아니며 `unmeasured`를 유지한다. `--note`에 실행 수단과 관측 시각·증거 위치를 남기되 토큰·쿠키·불필요한 계정 정보는 기록하지 않는다. 질문과 회차는 현재 측정 계획에 맞춘다.

Aside가 ChatGPT 구독으로 추론하는 것과 ChatGPT 웹에서 질의하는 것은 다르다. Aside 에이전트의 답을 대상 AI 웹 제품의 인용 관측으로 기록하지 않는다. 집계는 기존 `measure report`를 사용한다.

## Codex CLI 연결이 필요한 경우

이미 CLI로 호출할 수 있으면 MCP 등록은 필수가 아니다. 사용자가 등록을 요청하면 기존 서버 항목을 확인하고, 전역 설정을 변경하기 전에 백업한다. 설치 경로는 해당 환경에서 확인한다. 아래는 Windows 기본 설치 경로의 예시다.

```powershell
codex mcp add aside -- "$env:LOCALAPPDATA\Aside\CLI\current\aside.exe" mcp --host local
```

등록 후 새 Codex 세션에서 도구 목록과 읽기 전용 호출을 확인한다. 등록 성공과 실제 호출 성공을 구분한다. Aside 구독 인증은 Aside의 OAuth 연결로 관리하며 인증 값을 저장소에 복사하지 않는다.

## 검증 범위

2026-09-26의 한 Windows 환경에서 MCP 초기화·도구 목록·탭 개수 조회가 성공했고, 네 AI 웹 제품의 로그인된 새 대화 화면을 확인했다. 이는 모든 사용자의 세션이나 인용 수집 성공률을 보장하지 않는다. 전체 질의·출처 추출의 정확도와 시간 절감은 아직 비교 측정하지 않았다.
