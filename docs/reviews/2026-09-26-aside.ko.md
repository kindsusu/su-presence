# Aside 연계 검토

확인일: 2026-09-26. 선택적 브라우저 실행 수단이며 필수 런타임 의존성으로 추가하지 않는다.

## 판단

로그인이 필요한 ChatGPT·Gemini·Claude·Perplexity 웹 화면의 질의 실행과 출처 확인에 유용하다.
GSC·서치어드바이저는 읽기 권한이 있는 계정에서 보고서 조회·내보내기를 보조할 수 있다.
실제 계정별 성공률과 작업 시간 절감은 아직 측정하지 않았다. 원시 HTTP 진단은 기존 Python 도구를 유지한다.

## 서로 다른 두 연결

- 외부 에이전트 → Aside MCP/CLI: 브라우저를 조작하는 실행 수단이다.
- Aside → ChatGPT 구독 공급자: Aside 에이전트가 추론 모델을 쓰는 연결이다.

두 번째 연결로 생성한 답변은 ChatGPT 웹 검색 결과가 아니다. ChatGPT 웹 인용을 측정하려면
실제 해당 웹 UI에서 질의를 실행하고 답변의 출처를 관측해야 한다. API·웹 UI·Aside 에이전트
결과를 같은 표면으로 합산하지 않는다. 인증 토큰은 프로젝트 설정·코드·측정 로그로 복사하지 않는다.

## 기존 측정 흐름에 연결

1. `collect <audit.json> --browser`로 미측정 자리를 준비한다.
2. 현재 설치본의 `aside guide repl`과 도움말을 확인한다. 정확한 조작은 REPL,
   복합 작업 위임은 `aside exec`, MCP 지원 클라이언트 연결은 `aside mcp`를 사용한다.
3. [측정 실행 지침](../../ops/measure-playbook.md)의 고정 질문·언어·지역·검색 상태·로그인 상태·회차를 유지한다.
   중립적인 새 대화를 사용하고, Aside의 개인 기억이나 사이트 맥락이 대상 질문에 추가되지 않게 한다.
4. 응답과 인용 출처 URL을 직접 확인하고, 관측 시각·측정 표면·실제 모델(확인 가능할 때)·증거 위치를 남긴다.
5. 성공한 관측만 기존 `collect --record`로 입력한다. `--note`에는 Aside 사용 여부와 증거 위치를 적는다.
   이 명령은 `observed`를 기록하므로 로그인 실패·CAPTCHA·응답 확인 실패에 사용하지 않는다.
   실패하면 기존 `unmeasured`를 유지하고 실패 사유를 별도로 남긴다.
6. 기존 `measure report`로 집계한다. 별도의 Aside 성과 로그 형식을 만들지 않는다.

예시는 실제 관측값으로 바꾼 뒤 실행한다:

```bash
python tools/seo_geo.py collect <audit.json> --record chatgpt --query B1 --run 1 --cited https://example.com/page --brand yes --search on --login in --note "Aside REPL; evidence: <local-evidence-path>; observed-at: <timestamp>"
```

Aside 안의 ChatGPT 구독 연결은 제품의 OAuth 연결 절차로 관리한다.
MCP는 클라이언트가 지원하는 전송 방식에 맞춰야 한다. 로컬 stdio 서버가 모든 ChatGPT 환경에
바로 연결된다고 가정하지 않는다. 이번 검토에서는 전역 MCP 설정을 변경하지 않았다.

## 확인한 범위와 다음 검증

- Windows에서 Aside 프로세스와 CLI를 확인했다.
- 설치된 CLI의 `mcp`, `exec`, `repl` 명령과 도움말을 확인했다.
- `aside repl --host local`에서 탭 개수만 조회하여 로컬 브라우저 연결 성공을 확인했다.
- MCP 초기화·도구 목록 조회·REPL 탭 개수 호출도 성공했다.
- ChatGPT·Gemini·Claude·Perplexity에서 로그인된 계정 UI와 새 대화 입력창을 확인했다. 기존 대화 본문을 열거나 질문을 보내지는 않았다.
- 토큰·쿠키 값은 읽지 않았다. 실제 검색 질의나 계정 보고서 수집은 실행하지 않았다.
- 실행 시 선택 규칙은 [Aside 운영 지침](../../ops/aside.md)을 따른다.
- 다음 검증은 동일 질문·엔진·회차로 기존 방식과 Aside 방식의 완료율, 출처 추출 정확도,
  소요 시간과 호출 비용을 비교하는 작은 시험이다. 개선이 확인되면 선택적 실행 지침을 확장한다.
