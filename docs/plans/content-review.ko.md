# 본문 검토와 재측정 연결 계획

기준 커밋: `d2f7d2bc2653b23a97a64725207318d9bd4e8513` (3.0.0).
작업 전 `git fetch origin` 후 로컬 HEAD와 origin/main 일치, 미커밋 변경 없음 확인.

## 구현 범위

1. `rebuild review`: 완성된 Markdown/텍스트와 명시적으로 제공한 근거를 오프라인 검토한다. 초안 표시, 근거 원문 일치, 출처 날짜를 확인하고 의미·진실성 판단은 사람이 수행하도록 남긴다.
2. 외부 프로필의 브랜드명·분류·대상 고객을 제공된 기준 정보와 대조한다. 누락은 미확인, 차이는 검토 필요로 표시한다. 외부 서비스 게시·수정은 하지 않는다.
3. `rebuild protocol`: 동일 질문과 매체에 대한 반복 측정 슬롯을 생성한다. 브랜드 질문을 분리하고 분류가 없는 질문은 검토 대상으로 남긴다. 제품·모델·검색 모드·지역·세션 조건을 기록하며 언급과 URL 인용을 구분한다.
4. 기존 페이지 설계 산출물에 작성 후 검토 지침과 반복 측정 계획을 연결한다. 기존 실행 단계의 완료를 발행 승인으로 해석하지 않는다.
5. 사용법, 입력 예제, 회귀 테스트를 추가한다.

## 제한과 완료 조건

- FAQ·숫자·인용 개수를 임의의 필수 조건으로 삼지 않는다.
- 기계적 문자열 대조는 사실 검증이나 의미적 답변 품질 통과를 뜻하지 않는다.
- 크롤러 일괄 허용, 자동 게시, AI 학습 반영 시점·노출 성과 보장을 추가하지 않는다.
- 새로운 결과는 별도 실행 폴더에 보존한다. 기존 입력과 결과는 덮어쓰지 않는다.
- 오류 입력, 누락 정보, HTML 이스케이프, 반복 조건과 기존 워크플로 회귀 검증을 통과해야 완료한다.

참고: 사용자가 제공한 [작성 체크리스트](https://app.notion.com/p/AI-3f8063ed09fd813a99ade9d0e3f3d269). 내용과 표현을 복제하지 않고 검토 범위를 독자적으로 구성한다.

## 구현·검증 결과 (2026-10-19)

- 두 CLI와 기존 계획 JSON/Markdown/HTML 연결, 입력 예제, 한·영 사용 안내를 구현했다.
- Python 3.12.3에서 전체 테스트 474개 통과. 저장소 검증, doctor, Bash 회귀 검사 통과.
- 예제 파일로 두 CLI의 독립 실행과 새 출력 폴더 생성을 확인했다.
- 실제 외부 프로필 수집·게시나 AI 제품 응답 수집을 실행한 결과는 아니다. 프로토콜은 대기 슬롯을 만들며 미분류 질문은 검토 대상으로 남는다.
- 버전은 3.0.0으로 유지하고 변경 이력은 Unreleased에 기록했다.
